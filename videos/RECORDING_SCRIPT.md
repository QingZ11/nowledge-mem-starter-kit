# 3 段短视频录屏分镜脚本（约 5 分钟录完，无需配音）

> **设计原则**：每段控制在 60～90 秒、只录最容易点错的关键操作、不需要开口配音（录完原始 `.mov` 后可统一加中文字幕和步骤条，学生静音也能看懂）。

---

## 录前 2 分钟准备（防隐私泄露清单）

1. **切到干净的演示 Space**：在 Nowledge Mem 里新建并切换到一个空白 Space（例如 `Starter-Demo`），确保界面里**不出现任何个人或工作相关的真实记忆/线程**。
2. **清理浏览器与桌面**：
   - 浏览器开一个干净的新窗口（隐藏书签栏，避免露出私人书签）。
   - 关闭微信/飞书/通知弹窗（macOS 可临时开启「勿扰模式」）。
3. **统一窗口比例**：把 Mem / WorkBuddy / 浏览器窗口拉成近似 16:9 的舒适大小，字号稍微放大一档，手机端也能看清。
4. **macOS 零软件录屏方式**：按 **`Command + Shift + 5`** -> 选「录制所选部分」框选软件窗口 -> 点「录制」；录完点顶部菜单栏的停止按钮即可。

---

## 短视频 1：首次配置（约 60 秒）

**文件名建议**：`01-first-time-setup.mov`

| 时间段 | 操作画面 | 后期字幕文案 |
| --- | --- | --- |
| 00:00 – 00:15 | 打开 Mem -> 进入 `Settings -> Models` -> 将下载源切换为 **ModelScope** | 第 1 步：国内网络先把下载源切到 ModelScope（魔搭） |
| 00:15 – 00:30 | 展示索引模型下载/就绪状态（鼠标悬停在 `Ready / Active` 上停顿 2 秒） | 第 2 步：下载本地索引模型，看到 Ready 即完成（Windows 轻薄本可暂不下本地大模型） |
| 00:30 – 00:45 | 进入 `Settings -> Preferences -> Developer Tools` -> 点击 **Install bundled CLI** | 第 3 步：一键安装内置 CLI，不需要手动配环境 |
| 00:45 – 01:00 | 打开终端输入 `nmem doctor` 回车，展示连接正常输出 | 第 4 步：重开终端输入 nmem doctor，显示正常即通关 |

## 短视频 2：WorkBuddy 接入与验收（约 90 秒）

**文件名建议**：`02-workbuddy-setup.mov`

| 时间段 | 操作画面 | 后期字幕文案 |
| --- | --- | --- |
| 00:00 – 00:15 | 在 Mem 里快速新建 1 条测试记忆（如「本学期修《智能体》课程，项目方向是校园答疑助手」） | 先在 Mem 里存一条测试记忆，等会验证 AI 能不能搜到 |
| 00:15 – 00:35 | 打开 WorkBuddy -> `Plugins -> +` -> 粘贴完整的 `.workbuddy-plugin/marketplace.json` 链接 -> 安装 Nowledge Mem | 在 WorkBuddy 添加完整插件源地址（不要只填仓库名），点击安装 |
| 00:35 – 00:55 | 重启 WorkBuddy -> 打开 `Connections / MCP` -> 找到 `nowledge-mem` 并点击 **Trust** | 关键一步：安装后必须重启，并手动点击 Trust 授权连接 |
| 00:55 – 01:25 | 新建空白对话，输入「帮我查一下关于智能体课程的记忆」-> 展示调用 MCP 工具并准确回答 | 新开对话测试，看到调用 nowledge-mem 并答出记忆内容就成功了！ |

## 短视频 3：DeepSeek 网页版跨工具联动（约 60 秒）

**文件名建议**：`03-deepseek-cross-tool.mov`

| 时间段 | 操作画面 | 后期字幕文案 |
| --- | --- | --- |
| 00:00 – 00:20 | 打开 `chat.deepseek.com`，展示一段简短的课程方案对话（提前聊好 1～2 轮，省去等待生成时间） | 平时免费用 DeepSeek / 豆包 / Kimi 网页版查资料、聊方案 |
| 00:20 – 00:38 | 点击右上角 Nowledge Mem 浏览器插件 -> 点击保存当前对话/提炼记忆 -> 显示成功提示 | 点一下浏览器插件，把对话一键存入本地 Nowledge Mem |
| 00:38 – 01:00 | 切回 WorkBuddy 新开对话，问「我刚才在 DeepSeek 里聊的方案是什么？」-> 展示准确召回 | 回到 WorkBuddy 直接接着问，不同 AI 工具共享同一份长期记忆！ |
