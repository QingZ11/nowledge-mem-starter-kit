## 二、30 秒看懂：为什么在《智能体》课上用 Nowledge Mem？

在智能体（AI Agent）架构中，一个完整的 Agent 通常由三个核心部分组成：

```text
┌──────────────────────────────────────────────────────────┐
│                       AI Agent                           │
│                                                          │
│   ┌──────────┐      ┌───────────────┐      ┌──────────┐  │
│   │   LLM    │ ───▶ │ Tools / MCP   │ ───▶ │  Memory  │  │
│   │  (大脑)   │ ◀─── │   (手脚协议)   │ ◀─── │ (海马体)  │  │
│   └──────────┘      └───────────────┘      └──────────┘  │
│                                            Nowledge Mem  │
└──────────────────────────────────────────────────────────┘
```

大语言模型本身有两个天然限制：**上下文窗口有限**、**新开对话即失忆**；更常见的问题是，你在 DeepSeek 里聊过的思路，切到 WorkBuddy 写代码时它完全不知道。

**Nowledge Mem** 解决的就是 **Memory（长期记忆层）** 的问题：
- **本地优先**：你的笔记、论文摘录、项目决策和对话记录保存在本地知识图谱中，随时可检索、可追溯。
- **跨工具共享**：通过 **MCP（Model Context Protocol）** 和 **浏览器插件**，让 WorkBuddy、DeepSeek、Kimi、豆包、Cherry Studio 甚至你自己写的 Agent 共用同一套长期记忆。
- **自动沉淀**：借助生命周期 Hook，在对话结束或上下文压缩前自动归档，不再靠手动复制粘贴。
