# 04. 教授 / 助教课堂 15 分钟演示脚本

> **适用场景**：《大模型与 AI 智能体》课程实操环节 / 实验课开场。
> **核心策略**：课上**只统一走通 WorkBuddy 主线**（可控、不翻车），DeepSeek 浏览器插件演示 2 分钟种草，API 配置留作课后选修。

---

## 课前 5 分钟检查清单（防翻车关键）

- [ ] **提前建好干净的演示 Space**：在 Nowledge Mem 中切换到一个空白的演示 Space（如 `Agent-Course-Demo`），**避免投影仪投出个人或科研隐私记忆**。
- [ ] **测试教室网络**：提前在教室电脑上用浏览器打开一下 `https://raw.githubusercontent.com/nowledge-co/community/main/.workbuddy-plugin/marketplace.json`，确认能正常打开文本；如果教室网屏蔽了 GitHub Raw，提前通知学生切手机热点装插件（仅需几百 KB）。
- [ ] **提前发安装包/文档链接**：建议上课前 1 天把 [01. 学生上手指南](01-student-quickstart.md) 发到课程群，让学生提前把 Mem 桌面端和本地索引模型下好，课堂 15 分钟体验会顺畅一倍。

---

## 课堂 15 分钟节奏与演示话术

### 00:00 – 03:00｜概念破题：为什么智能体需要独立的 Memory 层？
- **板书 / PPT 展示**：`LLM（大脑） + MCP/Tools（手脚） + Memory（海马体）`。
- **一句话切入**：
  > 「大家平时写作业用 DeepSeek、写代码用 WorkBuddy，有没有发现每次新开一个窗口，AI 就像金鱼一样把你忘了？今天我们用 Nowledge Mem 给智能体装一个本地的、跨工具共享的长期记忆层。」

### 03:00 – 06:00｜展示 Nowledge Mem 与本地检索
- 切到 Nowledge Mem 界面，展示两条提前准备好的课程记忆（例如课程大作业要求、某个实验环境约定）。
- 演示搜索框毫秒级检索，顺带点一句：
  > 「用 Windows 轻薄本或无独立 GPU 电脑的同学，只需要保留默认的索引模型，不需要下载本地 LLM，避免电脑卡顿发烫。」

### 06:00 – 12:00｜核心实战：WorkBuddy 接入与现场验证
- **重点强调 3 个必踩坑**（一边演示一边口头提醒）：
  1. 确认 CLI：在 **设置 -> 通用 -> 开发者工具 -> 命令行界面** 确认显示绿色「已验证」，**装完/修完必须重开终端**。
  2. 装插件：粘贴完整的 `.workbuddy-plugin/marketplace.json` 链接，不要只填仓库名。
  3. 激活：装完**必须重启 WorkBuddy**，并在 `MCP / Connections` 里**手动点 Trust**。
- **现场 Demo**：
  - 在 WorkBuddy 新开一个空白对话，提问：*「查一下我们《大模型与 AI 智能体》课大作业的核心要求是什么？」*
  - 指给学生看屏幕上弹出的 MCP 工具调用过程，说明这就是课上讲的「Agent 主动调用 Memory Tool」。

### 12:00 – 14:00｜课后彩蛋：DeepSeek 网页版跨工具联动（种草环节）
- 切到浏览器里的 DeepSeek 网页版，展示右上角 Nowledge Mem 插件：
  > 「大家平时免费用 DeepSeek、豆包、Kimi 查论文、写代码，装上这个浏览器插件就能一键存进同一个记忆库，回来在 WorkBuddy 里直接接着用，不用花一分钱买 API。」

### 14:00 – 15:00｜布置极简课后小任务（可选，适合算平时分/实验打卡）
- **5 分钟打卡任务**：
  1. 在 Nowledge Mem 里存入 2 条自己的课程项目笔记；
  2. 在 WorkBuddy 里新开对话，让它通过 MCP 成功召回这 2 条笔记并截图；
  3. （选做）安装浏览器插件，从 DeepSeek / Kimi / 豆包里保存 1 段学习对话到 Mem。
